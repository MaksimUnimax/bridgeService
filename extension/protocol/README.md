# BB2D-P1 browser reference

`bb2d-p1.js` is a pure Web Crypto reference for canonical JSON, base64url, P-256 ECDSA/ECDH, HKDF-SHA-256 and AES-256-GCM. It has no DOM, storage, privileged API or network orchestration. The wire protocol uses `BB2D-P1`, strict sorted-key UTF-8 JSON, low-S P1363 signatures, a 15-minute in-memory session, 60-second messages and monotonic request sequence numbers.
